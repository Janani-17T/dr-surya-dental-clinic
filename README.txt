Dental Clinic Premium Website

How to run locally:
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Make sure files are named exactly:
   - index.html
   - style.css
4. Install the VS Code extension named Live Server.
5. Right click index.html and select Open with Live Server.

Important edits:
- Change clinic name in index.html wherever SmileCare is shown.
- Change phone number in index.html and WhatsApp link.
- Replace doctor name and qualification.
- Replace address with actual clinic address.
- Replace Google Maps placeholder later with actual Google Maps embed.
